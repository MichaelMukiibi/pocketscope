# Features

## Available

- Open the landing page and launch the throat capture demo.

- Take a photo on compatible devices or select an image from the file picker.
- Preview the capture and check throat visibility using a manual checklist.
- Save, list, and delete captures in local browser storage.
- See the browser's connection status.

## Planned
